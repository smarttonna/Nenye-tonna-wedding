# Chinenye & Tonna Wedding Invitation 💍

A luxury, bespoke digital wedding invitation and event hub celebrating the Holy Matrimony of **Chinenye & Tonna**.

## 📅 Event Information
* **Date**: Sunday, November 29, 2026
* **Time**: 12:00 PM Prompt
* **Location**: Abuja, Nigeria
* **Admission**: Strictly By Invitation (Admit 1 per card)
* **Children Policy**: No Kids Please
* **Colours of the Day**:
  * **Rose Pink** (`#CC7A8D`)
  * **Deep Olive** (`#556B2F`)

## ✨ Key Features
* **Bespoke Organic Invitation Card**: Tailored after the original physical invitation card with rose-gold metallic border, botanical foliage, and embossed golden wax seal (`C | T`).
* **Interactive Lightbox Modal**: High-resolution zoom preview of the official invitation card (`C&T Wedding Card.jpg`).
* **Live Countdown Timer**: Real-time ticker counting down to Sunday, November 29, 2026 at 12:00 PM.
* **Celebration Details**: Curated cards detailing schedule, venue directions, and dress code.
* **Interactive Dress Code Swatches**: 8-color palette showcasing Rose Pink, Deep Olive, Dusty Rose, Forest Olive, Blush Pink, Sage Olive, Warm Parchment, and Antique Gold.
* **Interactive RSVP Form**: Instant validation, guest attendance confirmation, prayer messages, and celebratory confetti shower animation with local storage persistence.
* **Dual Cash Registry / Gift Cards**: Individual cards for **The Bride** (`Igwegbe Chineye` · Access Bank) and **The Groom** (`Amazu Tonna` · Access Bank) with one-click copy and toast notifications.
* **Mobile-First Experience**: Designed with swipeable horizontal account cards, compact hero layout, and touch-optimized tap targets.
* **Floating Ambient Audio Player**: Built-in romantic acoustic harp melody.
* **Calendar Integration**: Instant Google Calendar event generator and Apple/Outlook `.ics` download.
* **Direct WhatsApp Logistics**: One-click chat with the wedding planning and logistics team.

## 🚀 Deployment
This static web application can be deployed instantly to:
* **GitHub Pages**: Go to **Settings > Pages > Source: Deploy from a branch (`main` / `/root`)**.
* **Vercel / Netlify**: Connect this repository for instant automated deployment.
